# Our Neighborhood, My Voice

청주 금천고등학교 1학년 공통영어1을 위한 50분 수업입니다. 학생이 **우리 동네에 관한 자기 생각**을 의견 → 이유 → 경험 → 바라는 점으로 연결해 영어로 씁니다.

교육과정 연결: `[10공영1-02-04] 자신의 생각이나 의견, 감정, 감상 등을 표현한다.` MCP 조회일: 2026-10-28. 5–7문장 및 도전 8–10문장은 수업 설계 목표입니다.

## 수업에서 사용하기

1. 홈페이지에서 ‘나의 동네 이야기 시작하기’를 선택합니다.
2. 여섯 단계를 진행합니다. 수준별 도움말과 예시 글은 필요할 때 펼칩니다.
3. 최종 글과 자기 점검을 완성한 뒤 ‘내 답안 PDF’를 저장합니다.
4. 공용 기기는 PDF를 확인한 뒤 ‘내 답안 초기화’를 누릅니다.

답안은 브라우저 localStorage에 저장됩니다. 서버 전송·교사 자동 제출·기기 간 동기화는 없습니다. 이름이나 정확한 주소는 필요하지 않습니다. 시크릿 창이나 저장 차단 환경에서는 PDF를 이용해 보관하세요. 교사용 가이드는 누구나 열 수 있습니다.

## 개발

Node.js 24 이상에서 `npm ci`를 실행합니다. `npm run preview`는 127.0.0.1:4173에 미리보기를 엽니다. 인터넷과 관련 인증서가 정상인 환경에서 `npm run prepare-assets`로 글꼴과 고정된 PDF 라이브러리를 준비할 수 있습니다. 배포에는 이미 포함된 assets를 사용하므로 외부 CDN에 연결하지 않습니다.

수업 내용은 `lesson.js`, 웹 동작은 `app.js`, PDF 구성은 `pdf-document.js`에 있습니다. 자료 수정 후 `npm run pdf`, `npm test`, `npm run verify-pdfs`를 실행합니다. PDF 검수 이미지는 `output/qa`에 생성되며 커밋하지 않습니다.

## 배포

GitHub Pages: Settings → Pages → Deploy from a branch → main / root. `.nojekyll`을 포함하며 모든 내부 리소스는 상대 경로를 사용합니다. 공개 저장소에는 학생 답안과 인증정보를 올리지 않습니다.

이 사이트는 학생 수업용 제작 자료이며 학교의 공식 홈페이지가 아닙니다. 예시 글은 가상의 학생 의견입니다. [출처 및 라이선스](THIRD-PARTY-NOTICES.md)를 확인하세요.
